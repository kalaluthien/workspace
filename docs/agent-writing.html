Brief naming a readable path

The run reads the file. It pins that file's repository with git rev-parse --short HEAD. Each citation carries the file, the line, and the commit of the repository the file sits in.

Brief naming no readable source

The run ends. It returns INSUFFICIENT-INPUT, names what is missing, and writes no HTML. A proposal brief takes no exemption here, because its AS-IS half still needs a readable source.

Render check of the built page

⚠️

Headless Chrome does not lay out below 500 CSS units. The script measures the width it received with window.innerWidth and prints it beside each render. A narrow render that reads as text cut off at the right edge is the instrument, not the page. .claude/skills/writing/scripts/render-check:19-23 @ a5b1501

check-figures holds 3× rule, and a figure passes all three.

  • Annotation floor — annotation text is at least 10 viewBox units.
    • A 10-unit label renders above the 8 px floor on a phone.
  • Pan threshold — a figure over 360 viewBox units carries class="pan".
    • Its <svg> takes an inline min-width equal to the viewBox width.
  • Maximum width — a figure viewBox is at most 620 units wide.
    • 620 units is the desktop measure.
