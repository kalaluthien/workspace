Placement

  1. 1 No scope holds every kind. Every scope leaves at least one kind empty.
    • Global carries no skill and no output style.
    • Workspace carries no agent.
    • Only notes/ among the five entries carries a skill or an agent.
  2. 2 One entry has no directory. kalaluthien.github.io/ has no .claude/.
    • The entry table sends its reader to _config.yml instead.
    • The absence is routing, not omission.
  3. 3 One kind has no format. The agent kind cites no written definition.
    • The other five kinds each cite one.
    • An author copies one of the agent kind's two worked examples.

Reach

  1. 1 Composition. A session composes the three scopes instead of choosing one.
    • The working directory selects two of the four sources.
  2. 2 Dormancy. A rule waits until the session reads a file its paths key matches.
    • Writing such a file never fires it.
  3. 3 Snapshot. Subagents inherit the composition as it stood at session start.
    • Skills hot-reload.
    • A new agent registers only on restart.

Routing

  1. 1 No self-placement. No file decides its own home.
    • Each scope declares its predicate in its own CLAUDE.md.
    • A router elsewhere assigns it.
  2. 2 Router position. A router sits at the outermost scope of its candidate set.
    • It never sits below one of its candidates.
    • A reader finds where a thing goes without opening any candidate.

Route 4 bars the global pool for the same reason route 3 owns it: there, a coordination procedure would hide behind a tool name that names only one of its parts.

Omissions

  • Two trees. The Commit field pins one of them.
    • It pins ~/workspace.
    • The configuration itself lives in ~/.claude at a644f45.
    • Its memory pools are in no repository.
  • File contents. The tables name files and kinds, never what a file says.
  • Harness machinery. Settings files, hooks, and plugin-supplied skills sit over the kinds, not in them.
    • agent-hooks.html covers the hooks.
  • Other project directories. ~/.claude/projects/ holds 14 directories.
    • 6 carry a memory/ pool.
    • The rest hold session transcripts.
  • Load mechanics. Not the load order, the token budget, or what wins when two scopes disagree.
  • History. Which scopes and entries existed before.
    • That log is the workspace pool's history-workspace-refactor.
