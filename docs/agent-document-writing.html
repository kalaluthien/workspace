Options

Conclusion
  1. 1Two axes. Locality — is the file that holds a rule loaded by the actor that must obey it, at the moment the rule binds; enforcement — what makes a violation fail rather than merely be discouraged.
  2. 2One axis decided it. Only Writer as constitution puts the rules in a file the acting agent already loads, and enforcement tied at nothing, because it is a machine check all three options need equally.

Recommendation

Conclusion
  1. 1Writer as constitution. One sentence governs it — a rule lives in the single file its actor loads at the moment the rule binds, and every other mention is a pointer — and the writer is the only actor that touches every view in every entry.
  2. 2The cost it accepted. The constitution lives in ~/.claude while the documents live in the entries, so no single commit changes a rule and the documents it governs together.
  3. 3The flip. It reverses if that split starts costing more than the locality it bought, or if the file grows until it reads as two documents, at which point the spec rules split into a file the spec template points at.

The smallest first step was one commit, and it is the one that landed: workspace 4ddc0d4 rewrote the definition to hold the rule set and shrank docs/README.md to the two-kinds table, the contract block and a pointer. Remainder

Three pieces of the recommendation did not land, and none of the three is decided here.

  • Enforcement — the workspace hook is the no-main-commits guard alone, camera’s runs its own script/check-docs.py, and board’s checks staged content for credentials, so scripts/check-docs is written and never run.
  • The shelf — of the five views in docs/, only agent-hooks.html carries the style layer, and the other four predate the kicker, the boxed conclusion and the highlight; whether to re-render them is an open owner decision.
  • The templates — the plan had them demote to skeleton plus machine contract, but they moved beside the constitution instead and still carry 546 comment lines of rule prose, and whether that relocation satisfies the plan is recorded nowhere.
