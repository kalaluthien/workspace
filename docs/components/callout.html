Each block below is its own example.

notice A notice is context the scanner must not miss. It never repeats the paragraph beside it; if the prose already says it, the block goes.
gap A gap records a defect and names its fix or owner. A document's gap blocks double as its open-item ledger: resolve the defect, remove the block, in one change.
warning Deleting the worktree deletes the shell's own working directory.
  • Consequence: every later command in the chain fails silently.
  • Avoidance: drive the worktree with git -C <path> from the main checkout instead of cd.
recovery Already deleted it? Your shell prints "no such file or directory" on any command. cd to the main checkout; the worktree's commits are safe — list them with git log --all.
